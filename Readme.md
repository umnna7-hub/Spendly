# 💰 Spendly - Mini Expense Tracker

Spendly is a simple personal expense tracking web application built to help users record, manage, and monitor their daily expenses.

## ✨ Features

- 📊 Dashboard for viewing expense information
- ➕ Add new expenses
- 🗑️ Delete individual expenses
- 🔍 Search and filter expenses
- 📈 Expense analytics and charts
- 💰 Monthly budget management
- 🎯 Set salary and savings goals
- ⚠️ Budget warning when spending reaches 80%
- 🚨 Over-budget notification
- 📅 Track expenses by date
- 💵 Calculate remaining monthly budget
- 🔄 Monthly budget carry-over for overspending

## 🛠️ Technologies Used

- **Python**
- **Flask**
- **MySQL**
- **HTML**
- **CSS**
- **JavaScript**
